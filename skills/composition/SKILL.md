# Composition

Compose each frame for the requested aspect ratio, with mobile readability as a priority. Establish focal point, visual hierarchy, balance, negative space, alignment, contrast, and safe areas. Keep important text and graphics away from edges. Prevent collisions, clipping, and overly dense layouts. Use camera framing and scale changes deliberately. Check the composition at target resolution and a reduced phone-sized preview.

**Deliver:** frame layout, focal hierarchy, safe areas, and camera framing.

**Quality checks:** one clear focal point, readable labels, balanced negative space, no clipping.
