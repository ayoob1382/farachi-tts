# Motion Design

Plan a coherent motion-graphics language for an educational video. Start from the narration's core message and audience. Define visual metaphor, hierarchy, palette, typography, spacing, shape language, and motion principles before designing scenes. Every animation must clarify a fact, relationship, sequence, or emotion; remove decoration that competes with comprehension. Keep styles consistent while allowing meaningful variation.

**Deliver:** visual direction, reusable design tokens, scene-by-scene intent, renderer notes.

**Quality checks:** clear meaning, consistent style, strong hierarchy, feasible implementation.
